# Fashion E-Commerce Platform

A full-stack single-vendor fashion e-commerce application.

## Technologies

### Frontend
- React
- Vite
- React Router
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Planned Features

- Product catalogue
- Product categories
- Shopping cart
- Customer registration and login
- Customer dashboard
- Order management
- Online payments
- Pay-on-delivery
- Admin dashboard
- Product and inventory management
- Responsive desktop and mobile interface

## Project Structure

- client/ - React frontend
- server/ - Node.js and Express backend
